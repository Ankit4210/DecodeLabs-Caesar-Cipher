# 🔐 DecodeLabs - Encryption & Decryption Project

A Python-based Encryption and Decryption project that demonstrates the basic working of cryptography using the Caesar Cipher Algorithm.

This project converts normal text (Plain Text) into a secured format (Cipher Text) using an encryption key and converts it back into the original message using decryption.

---

## 📌 About The Project

The main purpose of this project is to understand how secure communication systems work.

It shows the basic concept of:

- Encryption
- Decryption
- Secret Key
- Data Security
- Cryptography Basics

## ⚙️ How It Works

### Encryption

The user enters a message and a secret key.

Example:

Input:

```
HELLO
```

Key:

```
3
```

After encryption:

```
KHOOR
```

---

### Decryption

The encrypted message is converted back using the same key.

Example:

Input:

```
KHOOR
```

Key:

```
3
```

Output:

```
HELLO
```
